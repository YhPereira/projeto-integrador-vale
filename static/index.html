Sobre a equipe

Projeto de localização e controle de materiais em galpões.

Vale Localiza

Uma solução para reduzir o tempo gasto procurando ferramentas, peças e insumos, facilitando a consulta da localização e do status de cada item.

Objetivo: tornar a localização dos materiais mais rápida, clara e organizada.

Aplicação conectada a um banco SQLite local. Os dados e movimentações são armazenados no arquivo vale.db.

Manual do Usuário

Guia Passo a Passo de Utilização do Sistema Vale Localiza.

1. Visão Geral do Sistema

O Vale Localiza é a plataforma oficial desenvolvida para gerenciar, rastrear e controlar o inventário de ferramentas, peças e equipamentos nos galpões da empresa. Através dele, é possível saber exatamente onde um item está guardado, quem é o responsável atual por ele e o seu histórico de uso.

2. Consultando Materiais e Estoque

A tela inicial do sistema (Busca Rápida) permite localizar rapidamente qualquer ferramenta disponível na base de dados.

  1. Na tela inicial, utilize a Barra de Busca.
  2. Você pode pesquisar pelo código exato (ex: FER-992), pelo nome do equipamento (ex: Furadeira) ou até mesmo pela localização (ex: Galpão 03).
  3. Utilize os menus suspensos (filtros) para refinar a busca por Categoria, Galpão ou Status da Ferramenta.

3. Retirando e Devolvendo Itens

Para garantir a rastreabilidade, toda movimentação exige a identificação do colaborador responsável.

3.1. Como realizar uma Retirada

  1. Busque o item desejado. Ele deve estar com o status Disponível.
  2. Clique sobre o item e selecione a opção "Retirar".
  3. O sistema solicitará a sua Matrícula (ex: 8820). O sistema validará automaticamente se você é um colaborador ativo.
  4. Confirme a operação. O status do item mudará para Em Uso e seu nome ficará atrelado a ele.

3.2. Como realizar uma Devolução

  1. Busque o item que está sob sua responsabilidade (status Em Uso).
  2. Clique no item e selecione a opção "Devolver".
  3. Opcionalmente, insira uma observação sobre o estado da ferramenta (ex: "Entregue limpa e funcionando").
  4. Confirme a operação. O item voltará a ficar Disponível no estoque.

4. Manutenção e Ocorrências

O sistema permite registrar falhas ou perdas de equipamentos, bloqueando-os para uso futuro.

  • Enviar para Manutenção: Caso a ferramenta apresente defeito, selecione a opção "Enviar à manutenção". O status mudará para Em Manutenção e ela não poderá ser retirada até o retorno.
  • Marcar como Perdido: Se um equipamento for extraviado durante o uso, utilize a opção "Marcar perdido". O item ficará com status Perdido para posterior auditoria.

5. Histórico e Relatórios

Na aba Histórico de Movimentações, os gestores podem visualizar uma auditoria completa. Cada ação (Retirada, Devolução, Manutenção) é gravada com:
